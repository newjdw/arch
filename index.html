2. 한글 → 한자 변환

등록된 단어가 겹칠 경우 긴 단어를 먼저 적용합니다. 띄어쓰기·줄바꿈·괄호·쉼표 등은 그대로 유지됩니다.

3. 번호 대응 조회

항목을 선택하고 어느 한쪽 번호를 입력하세요.
예: ‘6차’ 표에 보고서 번호 125 ↔ 표준유물시스템 번호 7543이 등록돼 있으면 어느 쪽 번호로도 조회할 수 있습니다. 한 건이 조회되면 비고를 바로 입력·수정한 뒤 저장할 수 있습니다.

번호표 업로드 / 관리

첫 번째 열은 ‘보고서 번호’, 두 번째 열은 ‘표준유물시스템 번호’, 세 번째 열은 ‘비고’로 읽습니다. 비고는 비워도 됩니다. 첫 행에 보고서 번호 / 표준유물시스템 번호 / 비고 제목을 넣어도 됩니다. 같은 이름(예: 6차)으로 다시 업로드하면 기존 표를 교체합니다. 첫 번째 시트만 사용합니다.
현재 선택된 번호표 직접 편집
보고서 번호표준유물시스템 번호비고관리
직접 편집 표는 페이지당 50행씩 표시됩니다. 번호표가 300행을 넘더라도 모든 행을 페이지 이동으로 수정할 수 있습니다.

4. 한자 사전 관리

로컬 저장 모드
Firebase 설정 전에는 이 브라우저에만 저장됩니다.
한글한자관리
Firebase 연결 방법 / Rules 보기

이 HTML 파일 안의 FIREBASE_CONFIG 값만 자신의 Firebase 웹 앱 설정값으로 바꾸면 한자 사전과 번호 대응표가 Firestore에 저장됩니다. 

const FIREBASE_CONFIG = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  appId: "YOUR_APP_ID"
};

첫 테스트용 Firestore Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /dictionary/{docId} {
      allow read, write: if true;
    }
    match /numberSets/{setId} {
      allow read, write: if true;
      match /chunks/{chunkId} {
        allow read, write: if true;
      }
    }
  }
}

이 규칙은 링크를 아는 사람도 데이터를 수정할 수 있습니다. 개인용 시험에는 간단하지만, 장기 운용 시 로그인 제한을 추가할 수 있습니다.

Firebase 설정 시 한자 사전과 번호 대응표(비고 포함)가 클라우드에 저장됩니다. 설정 전에는 현재 브라우저에만 저장됩니다.
